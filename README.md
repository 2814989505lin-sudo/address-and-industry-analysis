# 地址智能分析、商圈画像与产业链指标

面向数据分析 / 算法岗位面试的 Python / SQL 项目合集，包含地址结构化、位置聚类、商圈画像、产业链指标计算与企业筛选。

本展示版保留核心处理逻辑、已有测试和技术说明，移除了真实业务数据、运行缓存、历史重复版本及硬编码连接凭据。

## 阅读导航

| 模块 | 解决的问题 | 可以重点查看的实现 |
|---|---|---|
| [地址结构化与商圈画像](projects/address-intelligence/README.md) | 将自由文本地址转为结构字段，归并位置标签并构建画像 | 规则解析、模型重建、位置聚类、聚类方案对比与空间画像 |
| [产业链指标与企业画像](projects/industry-chain/README.md) | 从产业链节点定义关联企业，计算企业画像并生成交付数据 | 指标口径、企业筛选、节点强度、推荐与交易特征 SQL |

地址模块内包含 [聚类方案对比](projects/address-intelligence/clustering/README.md)。建议先看地址解析与位置聚类，再看聚类方案取舍，最后查看商圈画像 SQL 和产业链指标。具体阅读入口及代码中的方法边界见 [分析与算法说明](docs/analysis-and-algorithms.md)。

## 项目范围

- **语言与工具：** Python、SQL、pandas、NumPy、SQLAlchemy、StarRocks、HTTP 模型服务；实验部分另使用 SciPy、scikit-learn、igraph 与 Leiden。
- **代码来源：** 从本地项目的交接目录、地址处理目录和实验目录中筛选；连接配置在展示副本中改为环境变量。
- **运行条件：** 数据库处理链路依赖原业务表结构及授权数据，无法仅靠仓库文件在空数据库中完成全流程。地址脚本的 Excel 输入也需自行准备。
- **验证边界：** 本地验证记录见 [验证说明](docs/verification.md)。没有连接生产数据库或调用付费 API；不声明未经测量的性能收益。
- **个人贡献：** 待项目所有者确认参与范围后补充，不根据文件名推断独立完成或团队职责。

## 配置和依赖

各模块提供独立 `requirements.txt`，依据源文件实际导入整理，尚未固定或验证完整依赖版本。`.env.example` 提供配置名与虚构示例值；不要提交真实 `.env`。

各脚本属于不同阶段的实现，其输入文件、工作表、区域和目标表配置也不同，请先阅读各模块运行边界。数据库脚本中仍保留业务表结构引用，以便阅读原实现；公开展示范围需由项目所有者确认。
